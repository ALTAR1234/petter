# Petter

A little jelly creature that lives along the bottom of your screen and reacts to what you're doing:

- dances in headphones while Listener plays, and names the song
- gets hyped while you game, and puts on glasses with a tiny laptop when you code
- grabs popcorn in Streamer, sends hearts in Socialer, and salutes Jarvis
- naps when you step away, and gets sleepy late at night

Click it to pet it. Drag it to pick it up and throw it. Right-click it to feed it, throw a ball, see a trick, rename it or change its colour. It earns XP from time together and from your attention, levels up, learns tricks (hop, spin, backflip, moonwalk, tornado), and wears a crown at level 5.

The window is transparent and click-through everywhere except the pet itself. Petter reads only the name of the program in front (every 2 seconds) and asks Listener what's playing through its local control channel.

## Run

```
npx electron .
```

## Build the installer

```
powershell -ExecutionPolicy Bypass -File install.ps1
```
